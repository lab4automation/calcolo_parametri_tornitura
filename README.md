# Calcolo Parametri Tornitura

Web app statica in HTML, CSS e JavaScript per il calcolo dei principali parametri di tornitura:

- velocita di taglio
- forza di taglio
- potenza di taglio
- tempi di lavorazione di sgrossatura e finitura
- volume e peso del materiale asportato

## Avvio

Apri `index.html` nel browser.

## File principali

- `index.html`: struttura dell'interfaccia
- `style.css`: stile della pagina e layout di stampa
- `script.js`: logica di calcolo e interazioni

## Nota

Il progetto è pensato come base evolutiva per gestire in futuro geometrie piu generiche rispetto a un semplice albero a 4 tratti cilindrici.
